# Get Shit Done (GSD)

A lightweight meta-prompting and autonomous execution system for AI coding agents.

## Core Workflows

- `plan-phase`: Break down complex features into phased execution steps.
- `execute-phase`: Run step-by-step implementation with continuous verification.
- `audit-milestone`: Review deliverables against requirements before signing off.
- `debug`: Systematic diagnosis and root-cause fix workflows.
- `verify-work`: Verify tests, lints, and builds before committing.
