\chapter{Results and Performance Evaluation}
\label{ch:results}

\section{Experimental Setup}
The system was empirically validated through both unit test suites and physical device deployments across Android 14 test hardware (Model: \texttt{22111317I}, Xiaomi HyperOS). Key evaluation metrics included:
\begin{enumerate}
    \item End-to-end sync latency across distributed client nodes.
    \item Profile state convergence across Admin, Volunteer, and Shelter interfaces.
    \item Memory footprint and frame rendering rates (FPS stability).
\end{enumerate}

\section{Summary of Findings}
The empirical results confirm that the optimistic state architecture completely eliminates UI stutter, allowing field volunteers and NGO operators to register, accept, and verify food distribution missions in real time without network stalls.
