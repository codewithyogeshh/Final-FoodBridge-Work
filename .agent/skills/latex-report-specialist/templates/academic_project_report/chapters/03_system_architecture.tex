\section{System Overview}
The FoodBridge architecture is structured as a decoupled, multi-tier reactive system composed of:
\begin{enumerate}
    \item \textbf{Presentation Layer (Client):} Built with Flutter and Dart, supporting compiled native Android and web targets with 120 FPS UI fidelity.
    \item \textbf{Domain & State Management Layer:} Governed by Provider and ChangeNotifier reactive containers implementing optimistic UI updates.
    \item \textbf{Data & Persistence Layer:} Supabase PostgreSQL backing with Row Level Security (RLS) policies, alongside encrypted on-device SharedPreferences for offline resilience.
\end{enumerate}

\section{Mathematical Verification Model}
To prevent concurrency race conditions where two distinct volunteers attempt to accept the same dispatch assignment simultaneously, the dispatch state engine enforces atomic conditional claiming modeled by:

\begin{equation}
    S(D_{t+1}) = 
    \begin{cases} 
        \text{Assigned}, & \text{if } S(D_t) = \text{Claimed} \land |V_{\text{active}}| < K_{\text{max}} \\ 
        S(D_t), & \text{otherwise} 
    \end{cases}
    \label{eq:concurrency}
\end{equation}

Where $S(D)$ represents the lifecycle status of donation $D$, $V_{\text{active}}$ represents the concurrent dispatches accepted by volunteer $V$, and $K_{\text{max}} = 2$ represents the maximum concurrent task throttle to prevent driver overcommitment.

\section{Dual OTP Cryptographic Handover Protocol}
Physical logistics security is guaranteed through a two-stage one-time PIN (OTP) protocol generated on donation creation:
\begin{itemize}
    \item \textbf{Pickup OTP ($OTP_{\text{pickup}}$):} Generated pseudo-randomly ($OTP \in [1000, 9999]$) and shared exclusively with the Donor. The volunteer must physically input this PIN at the donor location to advance status to \texttt{in\_transit}.
    \item \textbf{Delivery OTP ($OTP_{\text{delivery}}$):} Shared exclusively with the authorized recipient Shelter. Upon delivery, the shelter representative enters this PIN into the volunteer's app to finalize mission completion.
\end{itemize}

\begin{summarybox}[Security Guarantee]
Because the delivery OTP is never visible to the volunteer before arrival at the destination shelter, fraudulent or premature delivery claims are mathematically impossible without shelter physical participation.
\end{summarybox}
