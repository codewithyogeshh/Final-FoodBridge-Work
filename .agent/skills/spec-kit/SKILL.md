# Spec Kit - Spec-Driven Development

Structured specification and execution toolkit by GitHub.

## Core Phases

1. **Constitution & Guidelines**: Define architectural boundaries, tech stack constraints, and non-negotiables.
2. **Specification**: Write user stories, acceptance criteria, and edge-case contracts.
3. **Plan**: Architecture design, dependency graph, and step-by-step implementation phases.
4. **Tasks**: Fine-grained, testable task breakdowns.
5. **Verification**: Rigorous validation against specification criteria.

## Bundled Templates
See `./templates/` for checklists, plan templates, spec templates, and tasks templates.
